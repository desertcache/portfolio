How it was built

Built by a fleet of Claude agents working in parallel: one room per agent, an orchestrator enforcing a 300-line file limit and a typed room contract, and a headless Playwright pass screenshotting every named camera before any phase could merge. Sixteen functional tests (doors, quests, portals, save and load among them) gate every release, and the frame budget is measured on real hardware.

There are no asset files in the repo: every wall panel and floor streak is painted onto a CanvasTexture at runtime, and every planet outside the windows is procedurally seeded. The constitution the agents worked under is public: read CLAUDE.md and KICKOFF.md in the repo.
